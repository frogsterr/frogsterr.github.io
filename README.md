# Ben Shvartsman

Personal portfolio: an interactive frog walk through my studies, work, projects, and interests.

## Website

- Custom domain: https://benshvartsman.com
- Hosting: GitHub Pages
- Publish source: the root of the `main` branch

## Editing

Edit `index.html`, `style.css`, or `script.js`, then push to `main`. GitHub Pages automatically publishes the changes. The site uses plain HTML, CSS, and JavaScript, with local fonts and assets; no build step or dependencies are needed.

To preview locally, serve this folder with any static web server.

The frog responds to arrow keys and touch controls. The walk supports scrolling, keyboard navigation, and a vertical reading layout for reduced motion and short screens.

Company-logo source information is recorded in `assets/logos/sources.json`.
